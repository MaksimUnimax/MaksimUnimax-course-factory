# Course Factory

Course Factory is a source-grounded workflow for turning reference materials into educational courses.

Current status: bootstrap repository.

The project will first develop and test agent/skill methodology before building a backend or full UI.

## Local admin MVP

A local-only agent admin is available for editing markdown files inside `skills/` and viewing git status.

The server binds only to `127.0.0.1:8091`.

Saving changes updates files locally only. Commit and push remain separate Codex runs.
