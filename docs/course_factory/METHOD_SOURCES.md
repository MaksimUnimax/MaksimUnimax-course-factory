# Method sources

## METHOD_SOURCES_20260601_V0_1

Course Factory does not create courses from imagination.

Course Factory starts from four accepted methodology sources. These sources are a baseline for the first test bench, not permanent dogma.

## 1. The Carpentries

Use The Carpentries as the reference for practical lesson development.

Accepted principles:

- start from the target audience;
- use backward lesson design;
- define intended learning outcomes;
- create an outline before writing full lesson text;
- use exercises, examples, and feedback;
- treat lessons as practical training, not only reading material;
- keep lesson work git-trackable and reviewable.

Course Factory interpretation:

A lesson is not a text article. A lesson is a guided learning unit where the learner does something, checks the result, receives feedback, and can improve.

## 2. Open University / Learning Design

Use Open University Learning Design as the reference for making learning design explicit.

Accepted principles:

- learning design includes learning materials, activities, and assessments;
- learning design should not remain implicit in the author’s head;
- the learning experience should be planned, visible, and reviewable;
- learning activities should be tied to observable learner behavior.

Course Factory interpretation:

Every generated course must expose its learning design. The system must show what the learner reads, what the learner does, how the learner is assessed, and why the lesson is ordered that way.

## 3. Quality Matters

Use Quality Matters as the reference for rubric-based quality review of online courses.

Accepted principles:

- course quality must be reviewed against explicit standards;
- review must not be based only on taste;
- alignment matters: objectives, materials, activities, and assessments must support each other;
- online course quality requires clear navigation, learner support, measurable outcomes, and assessment consistency.

Course Factory interpretation:

Course Factory must have a quality gate. The reviewer must return PASS or FAIL with concrete reasons.

## 4. Rebus / OER approach

Use Rebus and OER production practice as the reference for educational resource production workflow.

Accepted principles:

- educational materials can be adopted, adapted, or authored;
- production can range from DIY to full-service workflow;
- authoring, editing, reviewing, publishing, and reuse are separate responsibilities;
- workflow design matters.

Course Factory interpretation:

Source owner, course designer, lesson writer, reviewer, and publisher are separate responsibilities. The system must not collapse all responsibilities into one uncontrolled generation step.

## Baseline limitation

These sources are enough to start Course Factory for practical, technical, onboarding, and workflow-based courses.

They are not enough by themselves for every domain.

If the requested course is school-standard, medical, legal, safety-critical, machine-operation, regulated, or age-specific, Course Factory must request additional domain-specific sources before generating final course content.
