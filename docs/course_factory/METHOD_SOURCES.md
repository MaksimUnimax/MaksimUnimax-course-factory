# Method sources

Course Factory starts from these methodology references:

1. The Carpentries  
   Used as a reference for practical technical lesson development, backward lesson design, intended learning outcomes, exercises, examples, feedback, and GitHub-based lesson workflow.

2. Open University / Learning Design  
   Used as a reference for making learning design explicit: learning materials, activities, assessments, and the structure of the learning experience.

3. Quality Matters  
   Used as a reference for course quality review, rubric-based evaluation, and quality gates for online learning.

4. Rebus / OER approach  
   Used as a reference for open educational resource production workflows: source owner, authoring, editing, review, publishing, and reuse.

These sources are a starting baseline, not permanent dogma.

If a course type is not covered by these sources, Course Factory must request additional methodology or domain-specific sources instead of inventing a course from general knowledge.
