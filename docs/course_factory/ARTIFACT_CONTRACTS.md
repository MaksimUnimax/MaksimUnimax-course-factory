# Artifact contracts

## ARTIFACT_CONTRACTS_20260601_V0_1

Each Course Factory stage must produce a concrete artifact.

Artifacts must be git-trackable text files unless a later approved design adds another format.

The required artifact shapes are derived from the accepted methodology references and the pipeline governance rules.

If a result looks poor, the fix is not to invent arbitrary fields from the current test topic. First determine whether the problem is the source materials, the methodology references, the domain references, the skill contract, the artifact contract, the quality gate, or the implementation.

## 1. Source digest

Required sections:

- Source inventory
- Main topics
- Key procedures
- Terms and vocabulary
- Target audience clues
- Safety constraints
- Contradictions
- Missing information
- License/privacy concerns
- Usable source facts
- Required human decisions

## 2. Course brief

Required sections:

- Course title
- Target audience
- Learner starting level
- Course goal
- Expected practical result
- Course format
- Scope boundaries
- Prerequisites
- Source basis
- Methodology basis
- Human approval points

## 3. Curriculum map

Required sections:

- Course title
- Lesson list
- Lesson order rationale
- Prerequisite chain
- Outcome per lesson
- Practice per lesson
- Assessment idea per lesson
- Difficulty progression
- Topics excluded from MVP

## 4. Lesson blueprint

Required sections:

- Lesson title
- Working situation
- Learner objective
- Previous knowledge
- Source basis
- Explanation blocks
- Worked example
- Learner action
- Practice task
- Assessment
- Common mistake
- Pass criteria
- Fail criteria
- Recovery guidance

## 5. Lesson text

Required sections:

- Lesson title
- Why this lesson exists
- Working situation
- What learner will be able to do
- Explanation
- Worked example
- Step-by-step learner action
- Practice task
- Mini-test or scenario check
- Common mistake
- How to check the result
- What to do if failed
- What comes next

## 6. Assessment set

Required sections:

- Assessment objective
- Questions or tasks
- Correct answers or expected outputs
- Why each answer is correct
- What misconception each wrong answer indicates
- Pass/fail rule

## 7. Quality review report

Required sections:

- Review status: PASS or FAIL
- Objective clarity
- Audience fit
- Source grounding
- Learner action
- Assessment alignment
- Difficulty progression
- Safety
- Missing parts
- Required fixes

## 8. Grounding review report

Required sections:

- Review status: PASS or FAIL
- Claims checked
- Claims grounded in source
- Claims marked as instructional inference
- Unsupported claims
- Source gaps
- Required fixes

## 9. Export package

Required sections:

- Target format
- Included artifacts
- Excluded artifacts
- Build instructions
- Known limitations
