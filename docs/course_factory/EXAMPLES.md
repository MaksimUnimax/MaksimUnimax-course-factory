# Examples

## EXAMPLES_20260601_V0_1

This file defines example principles for Course Factory.

Full good and bad examples will be added after the first test case.

## Bad example pattern — summary instead of course

Bad output:

- summarizes source materials;
- has no learner action;
- has no assessment;
- has no pass/fail rule;
- has no recovery guidance.

Why bad:

A summary is not a course.

## Bad example pattern — unsupported expert text

Bad output:

- uses source materials as inspiration;
- adds facts not present in sources;
- hides source gaps;
- sounds confident without evidence.

Why bad:

Course Factory must be source-grounded.

## Bad example pattern — vague objective

Bad output objective:

“Learner will understand Git.”

Why bad:

The objective is not observable.

Better objective:

“Learner can explain what commit and push mean, and can check whether a Codex run saved changes locally and remotely.”

## Bad example pattern — definition-only test

Bad output:

The lesson objective is practical, but the test only asks for definitions.

Why bad:

Assessment does not match objective.

## Good example pattern — practical lesson

Good output includes:

- working situation;
- measurable objective;
- short explanation;
- worked example;
- learner action;
- scenario-based check;
- common mistake;
- pass/fail criteria;
- recovery guidance.

## Good example pattern — reviewer report

Good review includes:

- PASS or FAIL status;
- defects tied to rubric criteria;
- required fixes;
- no rewriting of lesson by reviewer.
