# Quality rubric

## QUALITY_RUBRIC_20260601_V0_1

The Quality Reviewer must evaluate course artifacts by explicit criteria.

Review is not taste.

Review result must be one of:

- PASS
- FAIL_FIXABLE
- FAIL_SOURCE_GAP
- FAIL_METHOD_GAP
- FAIL_SAFETY_RISK
- FAIL_NOT_A_COURSE

The rubric is governed by the accepted methodology references and the methodology-reference governance rule.

If a course result is poor, the reviewer should identify the failure class before any UI or prompt change:

- missing source materials;
- poor or incomplete methodology reference;
- missing domain reference;
- weak skill contract;
- weak artifact contract;
- weak quality criterion;
- implementation error.

## Required checks

### 1. Source grounding

PASS when:

- factual claims are grounded in source materials;
- instructional inferences are marked;
- unsupported claims are not presented as facts.

FAIL when:

- lesson invents facts;
- source gaps are hidden;
- source contradictions are ignored.

### 2. Target audience fit

PASS when:

- lesson matches learner starting level;
- terminology is introduced before use;
- prerequisites are realistic.

FAIL when:

- lesson assumes knowledge not yet taught;
- lesson is too advanced or too vague.

### 3. Measurable objective

PASS when:

- learner objective describes an observable ability.

FAIL when:

- objective only says “understand”, “learn”, “know”, or “get familiar” without an observable action.

### 4. Learner action

PASS when:

- learner performs or simulates a real task.

FAIL when:

- lesson is only reading;
- lesson has no practical action.

### 5. Assessment alignment

PASS when:

- assessment checks the stated objective;
- practical objectives are tested with scenario or task checks.

FAIL when:

- assessment only checks definitions;
- assessment checks content not taught in the lesson.

### 6. Difficulty progression

PASS when:

- lessons build on previous knowledge;
- later lessons do not require unexplained earlier concepts.

FAIL when:

- course jumps into advanced tasks too early;
- lesson depends on future lessons.

### 7. Feedback and recovery

PASS when:

- learner can see why an answer or action is wrong;
- lesson gives recovery guidance.

FAIL when:

- learner only sees pass/fail without explanation.

### 8. Safety and responsibility

PASS when:

- safety-critical topics have boundaries and required supervision;
- legal, medical, financial, machine-operation, or regulated topics request domain sources.

FAIL when:

- course gives unsafe instructions without safety gate;
- course implies independent operation where supervision is required.

### 9. Course shape

PASS when:

- artifact is a course or lesson with sequence, action, assessment, and review.

FAIL when:

- artifact is only a summary, article, checklist, or marketing text.

## Final reviewer rule

The reviewer must not rewrite the lesson.

The reviewer must identify defects and required fixes.
