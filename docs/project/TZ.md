# Technical specification

## Goal

Create a workflow that can transform source materials into a structured educational course.

## Initial MVP

The first MVP is a file-based agent/skill test bench.

It must prove whether agents can reliably produce:

1. source digest;
2. course brief;
3. curriculum map;
4. lesson blueprint;
5. lesson text;
6. assessments;
7. quality review report.

## Non-goals for the first MVP

- no production backend;
- no database;
- no account system;
- no payments;
- no complex admin panel;
- no automatic publication;
- no unsafe handling of private or copyrighted materials.
