# Source Analyst input contract

## Обязательные входные данные

Source Analyst должен получить:

1. Список исходных файлов.
2. Содержимое исходных файлов или путь к source pack.
3. Цель анализа.
4. Предполагаемую аудиторию, если она известна.
5. Ограничения по использованию источников, если они есть.

## Допустимые источники

Допустимые входные материалы:

- markdown документы;
- текстовые инструкции;
- проектная документация;
- roadmap;
- правила работы;
- отчёты;
- manual;
- policy;
- transcript;
- source inventory.

## Недопустимые входные материалы без отдельного разрешения

- секреты;
- приватные ключи;
- токены;
- пароли;
- `.env`;
- пользовательские персональные данные;
- закрытые copyrighted материалы без разрешения;
- медицинские, юридические, safety-critical материалы без domain-specific источников.

## Что делать при неполном входе

Если входных данных недостаточно, агент не должен додумывать.

Он должен вернуть STOP с точным объяснением, чего не хватает.
